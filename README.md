## Selected projects

### [AgentRender MCP](https://github.com/corbinvachal48/agentrender-mcp)
**Web capture tools for AI agents · Public source**

AgentRender connects AI workflows to webpage screenshots, PDFs, and structured extracts through an MCP client and REST API. The public Python package includes installation instructions, client configuration, and an MIT license.

- Screenshot, PDF, and extract tools
- Stdio MCP integration for compatible clients
- Structured outputs and capture receipts
- Public source and documented setup

**My role:** Founder and product lead, directing the product concept, AI-assisted development, and iteration.

### G.O.D. Venture Kernel
**Experimental infrastructure for autonomous business execution**

A framework for turning business proposals into validated execution plans and measuring what an agent system can actually perform.

The implementation record documents a runnable kernel with a venture compiler, economic action graphs, capability registry, benchmark harness, autonomy scorer, and durable event ledger. It also documents 47 automated tests covering both successful fixture paths and failure cases.

**My role:** Project initiator and product owner, defining the autonomy goals, requirements, and evidence standards.

**Status:** Experimental implementation. Simulation results are distinguished from production evidence; real customer payment and autonomous delivery have not been established by the reviewed implementation record. Source is not currently published here.
